📊 1. Tự Động Bắn SĐT Khách Về Google Sheets Chưa gắn link Sheet

Vì khách chơi trên điện thoại của khách, bạn hãy dán Link Web App Google Sheets (hoặc Make/Zapier) vào ô dưới. Ngay khi khách nhập SĐT và trúng giải, hệ thống sẽ tự động bắn SĐT + Giải thưởng + Mã Voucher + Giờ chơi về file Google Trang Tính của quán!

Cách tạo file Google Sheets thu SĐT tự động miễn phí:
  1. Tạo 1 file Google Sheets mới ➔ Bấm menu Tiện ích mở rộng (Extensions) ➔ Apps Script.
  2. Xóa đoạn mã trống, dán đoạn mã bên dưới vào ➔ Bấm Triển khai (Deploy) ➔ Triển khai mới (New deployment).
  3. Chọn loại Ứng dụng web (Web app), mục Ai có quyền truy cập chọn Bất kỳ ai (Anyone) ➔ Copy URL dán vào ô trên!
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), d.phone, d.prizeName, d.code, d.gameName, d.zaloRemind]);
  return ContentService.createTextOutput("OK");
}
